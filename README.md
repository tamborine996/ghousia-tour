# Ghousia Masjid: walk-around tour

Concept model of the existing building, made from phone video with Pascal Editor (geometry) and Blender (baked light and
materials). Not surveyed: positions are typically within about 0.15 m, some areas are estimated, and nothing here is
suitable for planning or construction drawings.

Open `index.html` through the GitHub Pages link. Left thumb walks, right thumb looks; buttons: Real/Simple look, FX,
Walk/Run, Open doors.
